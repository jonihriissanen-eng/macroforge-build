# MacroForge

Standalone Windows macro recorder, auto-clicker, and key holder.

- Native C# WinForms application
- No Python, terminal window, or external runtime installation
- Multi-monitor mouse coordinates
- F8 record, F9 stop/save, F10 play, F6 auto-clicker, F7 key holder, F12 emergency stop
- Loop count where 0 means infinite
- Game Safe Mode disables automation and input hooks while Rocket League, Fortnite, or VALORANT is running
- Does not inject into games, read game memory, modify game files, or bypass anti-cheat

The Windows installer is built automatically by GitHub Actions and published as the `MacroForge-Setup` artifact.
